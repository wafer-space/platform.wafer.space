Verify Your Design File

Provide at least one checksum so we can confirm we received the exact file you intended to submit for manufacturing.

Use the checksum of your original, uncompressed GDS or OASIS file, not the compressed archive. If you uploaded design.gds.gz, enter the checksum for design.gds.

{# Collapsible Help Section #}

Generate checksums for your uncompressed GDS or OASIS file (before compressing it for upload).

Linux
md5sum your_design.gds       # MD5
sha1sum your_design.gds      # SHA1
sha256sum your_design.gds    # SHA256
macOS
md5 your_design.gds          # MD5
shasum your_design.gds       # SHA1
shasum -a 256 your_design.gds  # SHA256
Windows (PowerShell)
Get-FileHash -Algorithm MD5 your_design.gds     # MD5
Get-FileHash -Algorithm SHA1 your_design.gds    # SHA1
Get-FileHash -Algorithm SHA256 your_design.gds  # SHA256
Windows (Command Prompt)
certutil -hashfile your_design.gds MD5     # MD5
certutil -hashfile your_design.gds SHA1    # SHA1
certutil -hashfile your_design.gds SHA256  # SHA256
Remember: Generate the checksum from the original uncompressed file, not from any compressed version (like .gds.gz or .zip).
