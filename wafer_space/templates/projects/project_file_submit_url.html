Supported File Formats

This system accepts design files in GDS (GDSII) and OASIS formats. These are standard IC layout file formats used in semiconductor manufacturing.

Compressed files are supported: You can upload compressed archives (.zip, .gz, .tar.gz, .bz2, .xz, etc.) and the system will automatically extract the GDS or OASIS file contained within.

Provide a direct download URL to your file. The system supports common hosting platforms and will automatically rewrite URLs when needed (e.g., GitHub blob to raw URLs).

{# Hash Fields #} {{ form.expected_hash_md5|as_crispy_field }} {{ form.expected_hash_sha1|as_crispy_field }} {# Collapsible Help Section for Generating Checksums #}

Generate checksums for your uncompressed GDS or OASIS file (before compressing it for upload).

Linux / macOS
# Generate MD5 checksum
md5sum your_design.gds
# or on macOS:
md5 your_design.gds

# Generate SHA1 checksum
sha1sum your_design.gds
# or on macOS:
shasum your_design.gds
Windows (PowerShell)
# Generate MD5 checksum
Get-FileHash -Algorithm MD5 your_design.gds

# Generate SHA1 checksum
Get-FileHash -Algorithm SHA1 your_design.gds
Windows (Command Prompt)
# Generate MD5 checksum
certutil -hashfile your_design.gds MD5

# Generate SHA1 checksum
certutil -hashfile your_design.gds SHA1
Remember: Generate the checksum from the original uncompressed file, not from any compressed version (like .gds.gz or .zip).
